# Daylight Timeline evidence

Simulator captures from the refresh candidate, using isolated UI-test data.

- `today-unlogged.png`, `today-logged.png`, `today-reapply.png`: large iPhone,
  light appearance, first application and due reapplication states.
- `compact-dark.png`, `compact-accessibility.png`: compact iPhone on iOS 18.6,
  charcoal appearance; the latter enables accessibility Dynamic Type, Reduce
  Motion, increased contrast and differentiation without color.
- `ipad-history.png`, `settings.png`: iPad history and grouped destinations.
- `forecast.png`: directly labeled hourly UV with source and freshness.
- `watch.png`: Watch timing hierarchy and direct logging action.
- `motion.mp4`: iPad first log, History navigation and calendar expansion.

The recordings use native navigation and controls. They demonstrate simulator
presentation, not physical-device background notification delivery. Unit and UI
checks cover the retained mutation, automation and companion snapshot contracts.
