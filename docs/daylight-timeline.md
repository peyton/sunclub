# Daylight Timeline

Sunclub's daily loop uses chronological application events on an open cream or
charcoal canvas. Recorded events have filled markers; current and planned events
use outlined markers with explicit text. Today stays anchored to the current day,
with one logging action above compact, source-labeled UV context. History owns
date selection and editing. All existing automation and companion identities stay
unchanged.

## Shared presentation

- `SunTimelineEvent` supplies a decorative rail around accessible event content.
- `SunMotion` owns 120 ms press, 220 ms selection and 320 ms settling presets.
  Reduce Motion returns no animation. Success effects follow changed receipts.
- Native Liquid Glass remains on controls and navigation on iOS 26 and later;
  opaque semantic surfaces support earlier systems and accessibility settings.
- History, forecast, Insights, setup and editing use leading typography, grouped
  content and directly labeled information. Compact companions adapt the same
  last-applied/reapplication hierarchy without continuous animation.
