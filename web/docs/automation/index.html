Log sunscreen without breaking your stride.

Start in Apple Shortcuts

Create a shortcut or personal automation, then search for Sunclub. Add an action and choose when it runs.

Log Sunscreen
Save an application with optional SPF and notes.
Log Reapply
Record the next application after today’s first log.
Get Sunclub Status
Read today’s logging, UV, and reapplication status.
Time Since Last Sunscreen
Check how long it has been since your last application.
Set Sunclub Reminder
Change weekday or weekend reminder times.
Open Sunclub
Go to Today, History, Insights, or a Settings page.

More actions

The in-app Shortcuts Catalog also includes Save Sunscreen Log, Set Sunclub Reapply Reminder, Set Sunclub Toggle, Export Sunclub Backup, Export Sunclub History, and Create Logged Days Card.

You choose what’s allowed

In Settings → Shortcuts, control Shortcut writes, opening Sunclub from links, saving changes from links, and sharing result details independently. Apple Shortcuts controls execution confirmation.

Advanced links and compatibility

Find URL examples in the in-app catalog. Write examples are copy-only; read and open examples can be tested. Open Sunclub supports Sunscreen and Apple Health settings. Existing summary and achievements routes open Insights; health-report opens History, and product-scanner opens logging.

Privacy note

Actions use your Sunclub permissions. A log succeeds only after it is saved. Quick logs reuse recent SPF and coverage, but never copy notes automatically.
