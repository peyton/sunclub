Sunclub support

Sunclub does not require an account. For app issues, feedback, or feature requests, choose the contact route that best matches the issue.

Applies to Sunclub for iOS 18.6+.

Logging today

Open Sunclub and use manual logging from Home. SPF and notes are optional. If today is already logged, the app keeps one record for the day and lets your progress stay consistent.

Reminders

Check notification permission in Apple system settings, then review daily, reapply, and weekly reminder settings in Sunclub. Optional elevated UV reminders depend on the app's UV settings.

Live UV and location

Live UV is optional and off by default. When you enable it, Sunclub may use your location to request local UV forecasts from Apple Weather through WeatherKit. Manual logging continues to work if location, network access, or Apple Weather is unavailable. Learn how UV Index works.

Widgets and controls

If widget state looks stale, open Sunclub once so the shared snapshot can refresh, then return to the widget or Control Center action.

Shortcuts and URL actions

The Shortcuts Guide explains how to log sunscreen, check status, and connect Sunclub to Apple Shortcuts. You can manage automation writes in Sunclub Settings.

Backup and iCloud sync

Local backup export/import and private iCloud sync live in Settings. Imported backups can be reviewed before you publish imported changes to iCloud.

Before emailing support

  • Include your iPhone model and iOS version.
  • Describe what you expected and what happened instead.
  • For reminder issues, note whether notifications are allowed in Apple system settings.
  • For sync or backup issues, note whether iCloud sync is paused in Sunclub settings.
  • For Shortcut or URL issues, include the action name and whether URL writes are enabled in Settings -> Connect Shortcuts.
  • Include screenshots or device details only if you choose to share them.

Documentation

The docs collect setup notes for logging, reminders, widgets, Shortcuts, private sync, backup, and privacy. For Shortcut examples, read the Shortcuts Guide.

Security

For security reports, email security@mail.sunclub.peyton.app.

Privacy

Sunclub has no app-owned accounts, no ads, and no third-party analytics SDKs. Read the privacy policy for details about local storage, optional private iCloud sync, notifications, location, HealthKit, camera/product scanning, and backups.

General Contact

General questions can go to contact@mail.sunclub.peyton.app.

Medical Disclaimer

Sunclub is a habit tracker, not a medical device or medical advice. Follow sunscreen product directions and consult a qualified professional for medical questions.
